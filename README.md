# REA — Rapid Eye Analysis

> S 参数进，眼图和余量出

从 S 参数直接算眼图：Normal 与 Expert 共用 FFE / DFE / CTLE 优化流程，支持独立的浮动 FFE/DFE 抽头搜索。电眼之外也做光眼、TDECQ 与 EECQ，并给出 FEC 纠错前后的误码率。可以 SCPI 远程驱动，接进自动化测试流程。
